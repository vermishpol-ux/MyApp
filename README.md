# TutorDesk

TutorDesk — веб-приложение для организации работы частного репетитора: ученики, расписание, занятия, домашние задания, оплаты и прогресс обучения.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Технологии

React, TypeScript, Vite, React Router, Lucide Icons.

## Хранение данных

Данные пользователя сохраняются локально в браузере. В настройках доступны экспорт и восстановление резервной копии в JSON.
